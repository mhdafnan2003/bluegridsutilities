# Project Rules & Style Guidelines

## Banner & Image Overlay Rules
- **NO Blue Shades Over Image Banners**: Never place blue tinted overlays (`bg-[#0f3a5e]`, `bg-[#005f9e]`, blue gradients, or blue translucent containers) over image banners. Keep image banners clean, natural, and bright. When an overlay is necessary for text contrast, use neutral dark/black gradients (`from-black/85 via-black/55 to-transparent` or `bg-slate-950/70`) without any blue tinting.
